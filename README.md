# Анализатор метрик Джилба для кода на Ruby

Программа-парсер на **Python** с **графическим интерфейсом (tkinter)**.
Выполняет анализ исходного кода на языке **Ruby** и рассчитывает **метрики
Джилба** (метрики сложности потока управления):

* **абсолютную сложность CL**,
* **относительную сложность cl**,
* **максимальный уровень вложенности CLI**.

---

## 1. Состав проекта

```
gilb_core.py          — ядро анализатора (без зависимостей); можно запускать как CLI
gilb_gui.py           — графический интерфейс (tkinter)
tests/
  sample.rb           — подготовленная программа: все циклы + ветвления + case/when
  example_case.rb     — контрольный пример правила подсчёта (3 when → CL 3, CLI 2)
README.md
```

## 2. Требования

* **Python 3.8+** (проверено на 3.11).
* **tkinter** — обычно входит в состав Python.
  * Windows / macOS (python.org): tkinter уже установлен.
  * macOS (Homebrew): `brew install python-tk`.
  * Linux (Debian/Ubuntu): `sudo apt install python3-tk`.

Проверка: `python3 -c "import tkinter; print(tkinter.TkVersion)"`.

## 3. Запуск

### Графический интерфейс
```bash
python3 gilb_gui.py
```
«Открыть .rb файл…» (или «Загрузить пример», или вставьте код в левое поле) →
«Анализировать». Справа выводятся три метрики Джилба (CL, cl, CLI) и таблица
детализации управляющих конструкций.

### Консольный вариант (для отчёта)
```bash
python3 gilb_core.py tests/sample.rb
python3 gilb_core.py tests/example_case.rb
```

## 4. Метрики Джилба

| Метрика | Смысл | Формула |
|---------|-------|---------|
| **CL** | абсолютная сложность — количество условных операторов | CL = число условных операторов |
| **cl** | относительная сложность — насыщенность условными операторами | cl = CL / N |
| **CLI** | максимальный уровень вложенности условного оператора | — |

где **N** — общее количество операторов программы (оператор языка в
классическом понимании).

---

## 5. Правила подсчёта

### Абсолютная сложность CL (вклад условных операторов)

* каждый `if` и каждый `elsif` — по 1 (**ветка `else` НЕ учитывается**);
* каждый `unless` — 1;
* каждый тернарный оператор `cond ? a : b` — 1;
* каждый оператор цикла — 1: `while`, `until`, `for`, `loop`, а также
  итераторы с блоком (`each`, `times`, `upto`, `downto`, `step`, `map`, …);
* оператор множественного выбора `case`: учитывается **каждая ветка `when`**
  (**ветка `else` НЕ учитывается**). Три `when` → вклад 3.

Итог: **CL = (if + elsif + unless) + (число циклов) + (число ?:) +
(суммарное число веток when по всем case).**

### Общее число операторов N

N = (число простых операторов-инструкций) + CL. Простые операторы — это
присваивания, вызовы методов, `return` / `break` / `next` и т.п. (всё, что не
является управляющей конструкцией). Определения `def` / `class` / `module`
операторами не считаются. Такое построение гарантирует, что условные операторы
входят в N, то есть 0 ≤ cl ≤ 1.

### Максимальный уровень вложенности CLI (отсчёт ОТ НУЛЯ)

* управляющая конструкция на верхнем уровне имеет уровень **0**
  (например, одиночный цикл — вложенность 0);
* условный оператор **внутри** цикла имеет уровень **1**
  (уровень = число охватывающих условных/циклических конструкций);
* в операторе `case` **каждая следующая ветка `when` увеличивает уровень
  вложенности на 1**: 1-я ветка — базовый уровень, 2-я — базовый+1,
  3-я — базовый+2. Поэтому **три `when` дают максимальный уровень 2**.
* определения `def` / `class` / `module` / `begin` уровень вложенности **не**
  увеличивают.

**Что игнорируется:** содержимое комментариев (`#…`, `=begin…=end`) и строковых
литералов на токены не разбивается. Предполагается стандартный стиль оформления
(ключевые слова управляющих конструкций — в начале строки, закрытие блока —
`end` на отдельной строке).

## 6. Проверка на контрольном примере

Файл `tests/example_case.rb` содержит оператор множественного выбора `case`
с тремя ветвями `when` и веткой `else`:

| Метрика | Ожидается | Результат анализатора |
|---------|:---------:|:---------------------:|
| CL  | 3 (три `when`, `else` не считается) | **3** |
| CLI | 2 (уровни 0, 1, 2) | **2** |

### Результат для `tests/sample.rb`

Подготовленная программа содержит **все операторы цикла** Ruby
(`while`, `until`, `for`, `loop`, итераторы `each` и `times`), ветвления
`if/elsif/else` и `unless`, оператор множественного выбора `case/when`
и тернарный оператор:

CL = 14, N = 45, cl ≈ 0,311, CLI = 2.

(Значения воспроизводятся консольной командой из раздела 3.)

## 7. Что демонстрирует тестовая программа

* **все операторы цикла** языка: `while`, `until`, `for`, `loop`, итераторы
  `each`, `times`;
* **операторы ветвления** `if` / `elsif` / `else`, `unless`;
* **оператор множественного выбора** `case` / `when` / `else`;
* **тернарный оператор** `?:`.
